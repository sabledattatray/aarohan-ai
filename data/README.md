# Dataset licensing register

No third-party dataset has been acquired or approved for training. For the first tokenizer and training pipeline experiment, AAROHAN will use an original local corpus written specifically for this project. See [`corpora/original/`](corpora/original/) for the empty corpus template and its provenance manifest.

WikiText-2 has been selected as a possible next corpus. The user reports that a trusted adult reviewed the dataset page and approved local training use. The card states CC BY-SA 4.0, while repository license tags also list CC-BY-SA-3.0 and GFDL. Preserve attribution and all applicable share-alike notices. See [`wikitext2-review.json`](wikitext2-review.json) and the downloaded `data/raw/wikitext2-raw-v1/download-manifest.json`. Run the read-only split inspector before text processing or training; the dataset card does not supply a detailed personal-information review.

After a parent/guardian, teacher, or rights reviewer records an approval and terms in `wikitext2-review.json`, install the optional reader from `requirements-data.txt` and run `python scripts/download_wikitext2.py`. The script uses a pinned repository revision, preserves the original Parquet train/validation/test files, hashes each file, and never uses the test split for training. It refuses to download while review is pending.

Do not add text written by someone else, copied from a website/book, or generated by another model unless its source and license have been reviewed and recorded first. If using a work whose copyright status is uncertain, leave it out and ask an adult/rights holder to help check.

Each record must include:

- Dataset name and source URL/identifier
- Exact license and permitted uses, with review date and reviewer
- Collection date and dataset/version identifier
- Intended split/domain and processing version
- Record and token counts after processing
- Filtering statistics, checksums and attribution obligations
- Known privacy, copyright or other restrictions

For original material, also record the author (or authors), date created, confirmation that the text was written for this project, and permission for AAROHAN research/training use. Keep private details out of the corpus.

Keep evaluation material separate from all training and instruction-tuning data. Do not store credentials, personal datasets or large data artifacts in source control.
